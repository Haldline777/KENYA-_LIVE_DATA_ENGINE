
##  KENYA_LIVE_DATA_ENGINE

An automated, real-time data science pipeline designed to track, analyze, and visualize social and climate anomalies across Kenya. This project bridges data engineering with interactive analytics to provide actionable insights for environmental and societal monitoring.

###  Core Architecture & Features
*   **Automated Ingestion:** Python-driven workflows that programmatically fetch real-time environmental, climate, and social data streams.
*   **Data Pipeline & Cleaning:** Automated parsing, cleaning, and anomaly-detection modules built using `pandas` and statistical tracking.
*   **Power BI Integration:** Seamless live data connection pushing processed data points directly into a **Power BI dashboard** for real-time reporting.

### Tech Stack
*   **Data Engineering & Analytics:** Python, Pandas, NumPy
*   **Visualization & BI:** Power BI, DAX (Data Analysis Expressions)
*   **Automation:** Cron Jobs / Task Scheduling (or specify your automation tool, e.g., GitHub Actions, Airflow)
